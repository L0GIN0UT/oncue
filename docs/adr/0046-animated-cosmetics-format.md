# 0046. Формат анимированной косметики

- **Статус:** предложен (черновик; формат и публичный префикс выбраны владельцем 2026-10-23)
- **Дата:** 2026-10-23

## Контекст
Владелец: косметика анимированная с самого начала, фронт рендерит по `media_kind`. Нужен один формат
на проект: маленький, с прозрачностью (рамки и титулы лежат поверх интерфейса), с поддержкой во всех
целевых браузерах, без проигрывателя и без звука.

## Варианты
| Формат | Прозрачность | Размер | Поддержка | Замечание |
|---|---|---|---|---|
| Animated WebP | да (альфа) | малый | все современные браузеры | один `<img>`, покадрово просто; без управления воспроизведением |
| AVIF-анимация | да | самый малый | Chrome, Firefox, Safari 16.4+ | дорогое кодирование, слабее инструменты |
| Короткий mp4/webm | нет (webm VP9 с альфой — частично) | малый | везде | нужен `<video>`, автоплей-ограничения, лишний декодер |
| APNG/GIF | да / нет | большой | везде | размер и качество хуже |
| Lottie/SVG | да | малый | через библиотеку | зависимость и риск скриптов в SVG |

## Решение (владелец, 2026-10-23: animated WebP, публичный префикс)
- **Animated WebP** — единственный формат анимации; статика — WebP или PNG. Рендер — обычный `<img>`.
- `media_kind` в предмете определяет, показывать ли анимацию: при `prefers-reduced-motion` фронт
  показывает статичный кадр (`poster_key` — первый кадр, генерируется при загрузке).
- Лимиты (размер файла, габариты, число кадров, длительность, формат) — в конфиге progression,
  проверка при загрузке в admin: сигнатура файла, декодирование, отказ при превышении
  (защита от декомпрессионных бомб).
- Загрузка — админ через admin-API в S3 по образцу исходников media-pipeline. Картинки предметов
  отдаются по **публичному префиксу** (CDN или nginx перед S3, косметика не секрет); ключ объекта —
  случайный (`c/<128 бит hex>.webp`), без перечисления. Подписанные ссылки нужны только для UGC-аватарок
  ([0048](0048-promo-codes-custom-avatar.md)): они не публичны до одобрения.

## Последствия
- Формат можно сменить без миграции данных: `asset_key` указывает на объект, `media_kind` — на способ показа.
- Нужен проход проверки на `libwebp` в media-pipeline или admin-API (Pillow уже есть в media-pipeline).
