# 0051. Жалобы, комментарии и очередь модерации

- **Статус:** предложен (черновик; решения владельца — 2026-10-24)
- **Дата:** 2026-10-24

## Контекст
Нужны комментарии к сборникам, жалобы на игроков, сборники, комментарии и аватарки и ручная модерация без
автоматики. `PlayerForfeited` в контрактах нет; `MatchFinished.players[].finish` содержит `forfeit`, `left`,
`tech_loss`. `PlayerRated` с `kind=report|praise` уже публикуется match.

## Решение
- **Комментарии:** только к сборникам, плоские, ≤ 500 символов, проверка `gv_text.ugc` (denylist), лимит в минуту
  (конфиг), правка 5 минут, удаляют автор, автор сборника и модератор. Проекция сборников — из событий collections.
- **Жалоба:** причина из справочника (конфиг) + текст ≤ 300; одна на `(автор, объект)`. Жалоба на игрока — из
  `PlayerRated(kind=report)` или через API social при общем несоло-матче (`match_participants_proj`).
  Текст жалобы в события не попадает (ПДн).
- **Порог** жалоб на объект за сутки (конфиг) открывает `moderation_case` ровно один раз; до порога жалобы копятся.
- **Очередь** (админка): взять в работу, решить (отклонить / удалить контент / санкция), эскалировать; оптимистичная
  блокировка по `version`. Решение публикует `ContentModerated` и `ReportResolved` (по одному на заявителя →
  notifications `report_resolved`, только in-app). Автоматики нет, кроме порога.
- **Шкала порядочности:** счётчики `forfeits`, `leaves`, `reports_received`, `praises` из `MatchFinished.finish` и
  `PlayerRated`, видны только модератору, автосанкций нет. `PlayerForfeited` не вводим.
- Жалоба на аватарку идёт в очередь social; снятие — `ContentModerated` → media-pipeline. Общая очередь с
  UGC-изображениями media-pipeline — отдельным ADR позже.

## Последствия
События: `CommentPosted`, `CommentDeleted`, `ReportFiled`, `ContentModerated`, `ReportResolved`. `UserDeleted`
обезличивает комментарии и жалобы.
