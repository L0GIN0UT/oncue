# 0056. Награды события: ledger и предмет в инвентарь

- **Статус:** предложен (черновик; решение владельца — 2026-10-24)
- **Дата:** 2026-10-24

## Контекст
Награды события — деньги игры (Версы), опыт и предмет. Зона повышенной безопасности (ledger).

## Решение
- **Промежуточные награды** (Версы, опыт) находки — проводки ledger с `op_id =
  event:{run}:{find}:{user}`; `UNIQUE(op_id)` защищает от повтора и гонки. Суммы — в определении,
  верхняя граница в схеме `event_definition.v1.json`; потолки соло и онлайна не затрагиваются.
- **Основная награда** — предмет из каталога (обычно рамка) выдаётся навсегда при закрытии всех
  находок, `source = event`; нулевая проводка-отметка `event:{run}:complete:{user}` делает выдачу
  идемпотентной. Дубль предмета (уже есть) — без повторной выдачи, событие `EventCompleted` всё равно
  публикуется.
- **Временные предметы** (`expires_at`, `convert_condition`) в 5d не используются и не показываются.
- Всё в одной транзакции: прогресс находки, проводки, запись в outbox (`FindUnlocked`, `EventCompleted`).
- Остановка запуска не отзывает выданное; незавершённым игрокам награда за закрытие не выдаётся.

## Последствия
- Админ не выдаёт награды события вручную: ручная выдача остаётся через `ledger.grant` (ADR 0042).
- «Требуется ручная проверка владельцем» (ledger).
