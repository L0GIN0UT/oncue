# 0025. Динамические профили ассетов по `ClueAssetsRequested`

- **Статус:** предложено (план этапа 3a, утверждён владельцем)
- **Дата:** 2026-10-16

## Контекст
Профили ассетов media-pipeline заданы файлом `asset_profiles.yaml` (ADR 0020). Конфиг
режима с новыми уровнями загадки не играбелен, пока кто-то не добавит профиль и не
пересоберёт сервис.

## Решение
- Админ явно нажимает «Запросить ассеты» на черновике конфига. game публикует
  `game.ClueAssetsRequested` (`clue_type`, `params`, `params_hash`).
- media-pipeline проверяет `params` генератором, заводит **динамический профиль** в БД
  (дедупликация по `params_hash`, лимит `GV_MEDIA__MAX_DYNAMIC_PROFILES`) и досоздаёт
  наборы порциями периодической задачей.
- Статус профиля админка читает через admin-API media-pipeline (ADR 0013); обратного
  события нет.

## Последствия
- Новый набор уровней не требует релиза. Автоматического запроса при сохранении
  черновика нет: опечатки не порождают шторм генерации.
- Нагрузка на ffmpeg и S3 ограничена лимитом профилей и размером порции.
