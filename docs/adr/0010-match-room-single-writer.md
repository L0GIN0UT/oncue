# 0010. Single-writer для комнат матча

- **Статус:** принято
- **Дата:** 2026-10-07

## Контекст
Комната матча — состояние, которое меняется командами нескольких игроков и таймерами. При нескольких инстансах match возможны гонки.

## Решение
У каждой комнаты один владелец (lease в Redis с продлением). Команды перенаправляются владельцу через Redis Stream комнаты и применяются последовательно. Состояние снапшотится с версией. При падении владельца комнату захватывает другой инстанс.

## Альтернативы
- Распределённая блокировка на каждую команду: задержки и сложные отказы.
- Sticky-сессии на балансировщике: игроки комнаты могут попасть на разные инстансы, таймеры остаются без владельца.
- Акторный фреймворк (Orleans/Akka): нет зрелого аналога в Python.

## Последствия
- (+) Нет гонок, простая логика автомата, понятное восстановление.
- (−) Нужна аккуратная реализация lease и handoff, покрытая тестами.
