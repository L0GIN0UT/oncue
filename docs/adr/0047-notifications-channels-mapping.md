# 0047. Notifications: каналы, маппинг событий, порт Push

- **Статус:** предложен (черновик; решения владельца — 2026-10-23)
- **Дата:** 2026-10-23

## Контекст
Игроку нужны уведомления о значимых событиях (уровень, бейдж, задание, награда, решение модерации).
Сервис некритичен и не публикует событий — он терминальный потребитель.

## Решение
- **Каналы 5b:** in-app (список, непрочитанные, «прочитать все») и realtime — публикация в личный канал
  Centrifugo (connection-токен уже выдаёт identity, [0035](0035-realtime-centrifugo-tokens-and-tick.md)).
  Запись в БД первична: недоступный Centrifugo не теряет уведомление, клиент догоняет списком.
- **Маппинг «событие → тип уведомления» и шаблоны** — конфиг (`contracts/notifications/notification_types.v1.json`,
  схема в `contracts/`), с локализацией (ru сейчас). Новый тип — данные, не код; нет шаблона —
  конфиг не проходит проверку при старте.
- **Типы 5b:** новый уровень, бейдж, задание выполнено, награда недели/сезона, решение по аватарке (`media_pipeline.AssetModerated`).
  Отключение по типам — настройка пользователя (`preferences`).
- **Идемпотентность:** ключ уведомления — предмет события (`dedup_key`), не `event_id`; inbox поверх.
- **E-mail — только организационный:** ответ поддержки, информационная рассылка от админа
  (согласие и отписка по персональной ссылке с непрозрачным токеном, без согласия не уходит), решения по жалобам (5c).
  Для заявок и игровых событий почты нет. Отправка — существующий `SmtpEmailSender`/log по образцу identity.
- **Push:** порт `PushSender` и таблица `devices`; реализации нет (мобильная версия после релиза),
  по умолчанию `NullPushSender`.
- **Мутации** (прочитано, настройки) идут из браузера: сервис входит в `COOKIE_MUTATION_SERVICES`.

## Рассмотренные альтернативы
- Уведомления только realtime без БД — теряются при отсутствии клиента.
- Синхронный вызов notifications из progression — запрещён (цепочки A→B).
- Шаблоны в коде — правило «ничего не хардкодить».

## Последствия
- Новые события других сервисов подключаются конфигом маппинга и (при необходимости) consumer-ом.
