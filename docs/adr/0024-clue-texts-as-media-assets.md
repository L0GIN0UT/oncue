# 0024. Тексты загадок — ассеты media-pipeline, курирование в catalog

- **Статус:** предложено (план этапа 3a, утверждён владельцем)
- **Дата:** 2026-10-16

## Контекст
Загадки `description` и `emoji` — текст, а не медиа. Отдать текст прямо из проекции game
проще, но тогда у текстовых загадок своя модель играбельности и своя защита от
подглядывания уровней.

## Решение
- Тексты (`plot_masked`, `tagline`, `emoji`) хранит и курирует catalog: черновик →
  одобрение модератором. Сюжет из TMDB маскируется автоматически (название, алиасы,
  имена персон), но в событие попадает только после одобрения.
- Одобренные тексты уходят в `catalog.MediaItemCreated/Updated.clue_texts`.
- media-pipeline генерирует по уровням JSON-ассет (`contracts/clues/text_asset.v1.json`)
  и выдаёт его по подписанной ссылке, как кадры и звук (ADR 0012).

## Последствия
- Античит, играбельность по `params_hash` (ADR 0020) и выдача уровней одинаковы для всех
  загадок; свои ассеты сборников (этап 3b) пойдут тем же путём.
- Правка текста после одобрения возвращает его в черновик; новое одобрение — новое
  поколение ассетов.
