# 0079. Обложка карточки сборника - artwork первой единицы

Статус: принято. Уточняет [ADR 0028](0028-collections-versions-draft-projection.md) и [ADR 0073](0073-reveal-artwork.md).

## Контекст
Карточки сборников показывали серую заглушку или пресет (градиент и эмодзи). Нужна картинка. Id единиц публичный API collections не отдаёт тем, кто сборник не прошёл (D6), а цепочки A->B->C между сервисами запрещены.

## Решение
- Обложка - `artwork` первой по `position` единицы: `cover_artwork {url, expires_at, mime} | null`.
- bff_web собирает её сам, двумя пакетными вызовами на ответ: `collections POST /internal/v1/cover-items` (область `covers.read`) -> `media-pipeline POST /internal/v1/cover-links` (область `assets.cover_link`). collections media-pipeline не вызывает; публичные ответы collections не меняются.
- `cover-items` отдаёт единицы только опубликованных ПУБЛИЧНЫХ сборников (unlisted, черновики, скрытые, удалённые и неизвестные неразличимо отсутствуют), лимит пакета - настройка.
- `cover-links`: ссылка кратна окну (час), стабильный URL работает на кэши браузера; заблокированные и без картинки пропускаются.
- Для списков, которые фронт берёт напрямую из collections, bff даёт `POST /v1/collections/covers`; id единиц не раскрываются, закрытые сборники и сборники без картинки неотличимы (`null`).
- Деградация: нет токена/прав, таймаут, breaker у любого из двух источников - `cover_artwork: null`, страница не падает (фронт показывает пресет).
- Права: клиент `bff_web` в `GV_SERVICE_CLIENTS` получает аудитории `collections: [covers.read]` и `media_pipeline: [assets.cover_link]`.

- Осознанное уточнение ADR 0073 и D6: `artwork` первой единицы публичного сборника видна на карточке до игры (при игре без перемешивания это картинка ответа первого раунда). Решение владельца; смягчения при необходимости - отдельный размытый профиль `cover` или обложка, выбранная автором и исключённая из раундов. Id единиц наружу не уходят.

## Последствия
- (-) `cover-links` пишет строку журнала выдачи на каждую единицу пакета и читает наборы по одному; кэш связки `collection_id -> link` в bff до `expires_at` - возможное следующее улучшение.
- (+) Контракты только расширены (необязательное поле, новые ручки).
- (-) Два дополнительных внутренних вызова на ответ каталога (при сбое - без обложек, срок ограничен `GV_PAGES__COVERS_DEADLINE_S`).
- (-) Публичный кэш витрин держит ссылки до 90 с; срок ссылки не короче часа.
