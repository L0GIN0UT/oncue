# 0078. Кадр без приближения: уровни `frame_progressive` различаются только размытием

- **Статус:** принято
- **Дата:** 2026-11-06
- **Уточняет:** ADR 0025 (профили ассетов); `docs/02-game-engine.md` (`frame_progressive`)

## Контекст
Раньше каждый уровень сочетал размытие и приближение: `crop` 0.35, 0.5, 0.7, 1.0, 1.0, 1.0, то есть
первые три уровня показывали увеличенный центральный фрагмент кадра.

## Решение
- Приближение убрано полностью. Профиль `frame_progressive/default` и сиды режимов содержат только
  `blur_px` (25, 20, 15, 10, 5, 0) и `max_width: 960`: весь кадр, один размер на всех уровнях.
- `crop` остаётся допустимым и необязательным (по умолчанию 1.0) в JSON Schema, модели ядра и модели
  media-pipeline; профиль `frame_progressive/still` не менялся.
- `params_hash` профиля изменился (`contracts/clues/params_hash.golden.json`).

## Последствия
- Версии режимов в game неизменяемы: правка сидов создаёт новую версию при bootstrap, старые сессии
  остаются на прежней версии.
- После выкатки нужна перегенерация наборов: `gv dev replan-assets --clue-type frame_progressive`.
- Подбор других значений размытия - отдельное решение владельца.
