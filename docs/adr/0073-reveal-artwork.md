# 0073. Обложка и постер в ревиле раунда (`Reveal.artwork`)

- **Статус:** принято
- **Дата:** 2026-10-29
- **Уточняет:** ADR 0025 (профили ассетов), ADR 0072; зона повышенной проверки — загрузка файлов
  (`docs/10-ai-assistant.md` §3)

## Контекст
Ревил завершённого раунда несёт только финальную подачу загадки. Фронтенду v3 нужна картинка
ответа: обложка альбома у трека, постер у фильма. Постеры у фильмов уже есть (`poster`), для
треков картинок в системе нет.

## Решение
- **Вид исходника `cover`** (`source_media.kind`): обложка альбома трека. Семейство — изображение,
  грузится так же, как `poster` (админка, `POST /admin/v1/sources`, роль `cover` в манифесте
  пакета). Для файла `cover` действуют свои лимиты (`GV_MEDIA__COVER_*`): байты — при чтении
  загруженного файла и до декодирования (границу тела запроса до разбора multipart держит
  gateway), стороны и пиксели — по заголовку до декодирования, ровно один кадр, результат пересобирается из
  пикселей (без EXIF/ICC).
- **Новый тип загадки `artwork`** (одноуровневый, плагин-генератор): одна картинка нужного размера в
  WebP. Профили `artwork:default` (музыка: `source_kinds: [cover]`, 600×600) и `artwork:film`
  (`source_kinds: [poster, frame]`, 600×900; `default` обязателен каждому типу, поэтому у музыки он),
  размеры, способ вписывания (`fit`) и порядок видов — в конфиге профиля
  (`asset_profiles.yaml`), не в коде. Генератор берёт первый подходящий вид по порядку: у фильма
  без постера подставляется кадр; нет ни одного — набора нет. Остальная цепочка не меняется:
  `AssetsReady`, проекция `clue_assets` в game, подписанные ссылки, блокировка единицы, backfill.
- **game:** `Round.artwork_asset` (необязательное поле в JSON раунда, DDL не нужен). Профиль
  artwork по домену — настройка game `GV_GAME__ARTWORK_PROFILES` (env, не `mode_config`);
  contract-тест сверяет её с `contracts/clues/params_hash.golden.json`. `Reveal.artwork` —
  `{url, expires_at, mime}` или `null`: нет набора, единица заблокирована, media
  недоступен — ревил отвечает как раньше. До завершения раунда artwork нигде не выдаётся.
- **Манифест пакета:** роль `cover` добавлена в enum ролей схемы `media_package_manifest.v1.json`
  (версия формата 1.1, поле `version` остаётся `1`: расширение enum входа совместимо, старые пакеты
  разбираются как раньше).
- **Админка:** загрузка и просмотр обложки (поток WebP через media-pipeline,
  `GET /admin/v1/sources/{id}/preview`, право `admin.access`; admin отдаёт её браузеру прокси
  `/catalog/sources/<id>/preview/` без токенов и адресов S3). Фильтр «без обложки» и ручка под него
  не делаются (отложено, `docs/backlog.md`).
- **Не входит:** онлайн-ревил (`match`: дуэль и party отдают `artwork: null`) — отдельный этап;
  заглушку при `null` рисует фронтенд.

## Последствия
- (+) Новых событий, таблиц game и межсервисных вызовов на пути данных нет; новый тип — плагин.
- (+) Старые клиенты видят лишнее необязательное поле.
- (−) Профили artwork создают наборы для всех единиц домена (нагрузка на воркер при первом
  применении; `media.profiles.backfill`).
- (−) Один дополнительный вызов выдачи ссылки на ревил (лимитер media учитывает его).
- Миграция БД — только media и только расширяющая: CHECK `source_media.kind` получает `cover`.
