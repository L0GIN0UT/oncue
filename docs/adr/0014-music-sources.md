# 0014. Источники музыкальных метаданных и аудио

- **Статус:** принято
- **Дата:** 2026-10-09

## Контекст
У Яндекс Музыки нет официального публичного API. Превью Spotify для новых приложений недоступны, условия Deezer/iTunes ограничивают использование превью в играх. Метаданные (названия, артисты, популярность) — фактические данные; аудиозаписи — объект авторского и смежных прав.

## Решение
- Метаданные — через порт `MusicMetadataProvider` в catalog. Адаптеры: импорт из файла (по умолчанию), MusicBrainz (CC0), Spotify Web API (официальный, client credentials), неофициальный клиент Яндекс Музыки — **только метаданные**, выключен по умолчанию; риск нарушения условий сервиса принят владельцем проекта.
- Аудио — только из источников с правом использования: загрузка правообладателем или администратором, сиды. Загрузка аудио с пиратских площадок и через неофициальные клиенты стримингов **не реализуется**.
- До публичного запуска выбирается лицензированный источник отрывков (лицензия правообладателей, агрегатор с правом на превью или собственные соглашения).

## Последствия
- (+) Каталог можно наполнять уже сейчас; источник аудио заменяем без изменения игровой логики (порт в media-pipeline).
- (−) Наполнение аудио в этапах 1–5 — ручное или из сидов.
- (−) Неофициальный клиент Яндекса может перестать работать в любой момент — изолирован за портом, с circuit breaker.
