# 0077. Предзагрузка уровня 1 следующего раунда (`next_round_first_clue`)

- **Статус:** принято
- **Дата:** 2026-11-05
- **Уточняет:** ADR 0012 (подписанные ссылки), ADR 0073 (ревил); зона повышенной проверки — выдача ссылок

## Контекст
После завершения раунда клиент ждёт `POST .../clue`, скачивает ассет и только потом играет:
между раундами возникает пауза. Фронтенд предложил отдавать ссылки заранее.

Ссылки подписывает nginx `secure_link` (`md5(expires + uri + секрет)`): параметра «действительна
не раньше» нет, любой, у кого есть URL, открывает его сразу. Очки считаются по уровню, на котором
пришёл точный ответ, а в соло XP и версы идут из очков (`GameFinished` → progression), поэтому
ссылка на следующий УРОВЕНЬ текущего раунда даёт больше информации за те же очки.

## Решение
- **Выдаём только `next_round_first_clue`** - уровень 1 следующего раунда, и только когда
  предыдущий раунд завершён, а следующий ещё не начат (`started_at` пуст). Уровень 1 клиент и так
  получает при старте раунда, лишнего знания нет, выигрыш - время загрузки.
- **`next_clue` (следующий уровень текущего раунда) не делаем.** Безопасного варианта нет:
  `not-before` в подписи потребовал бы правки nginx и `links.py` и лишил бы предзагрузку смысла;
  остаётся шифрование медиа с ключом на открытии уровня - отдельная большая задача.
- **Флаг режима `features.preload_next_round`**, по умолчанию выключен. Включён в сидах
  `*.random.*` и `*.collection.*`; дейлики, режимы с рекордами, пары, сетка и онлайн-режимы
  выключены.
- **Валидатор конфига** (`config.preload_unsafe`) запрещает флаг в онлайн-режимах (включая
  рейтинговые; с ADR 0080 допустим нерейтинговый онлайн) и при скорере по времени (`Scorer.time_based = True`: `by_speed`, `party_speed`) -
  иначе клиент мог бы послушать до старта таймера.
- **Где поле:** `SessionSnapshot.next_round_first_clue` и `MoveResult.next_round_first_clue`
  (`ClueOut | null`). Таймер не запускается, раунд не аннулируется при сбое выдачи: любой сбой
  (набор выключен, media недоступен, лимит) даёт `null`.
- Комнаты (match) - решение принято в [ADR 0080](0080-online-next-round-preload.md): по флагу режима,
  только не рейтинг и скорер не по времени, с перевыдачей владельцем по образцу `Reveal.artwork`.
  Запрет флага для онлайна из этого ADR ослаблен: допустим нерейтинговый онлайн с очками по уровню.

## Последствия
- (+) Нет паузы между раундами в режимах с флагом; контракты расширены необязательным полем.
- (-) Лишний вызов выдачи ссылки на завершении раунда (кэш `RevealLinkCache`, лимит media учитывает).
- (-) Пауза при «пропустить» внутри раунда остаётся: без шифрования её убрать нельзя безопасно.
- Идемпотентный повтор хода возвращает сохранённый ответ; ссылка в нём может быть просрочена,
  клиент тогда просто просит ассет обычным `POST .../clue` (или перечитывает снимок: `GET /sessions/{id}` выдаёт свежую ссылку).
