# 0026. Ревил ассетом другого типа — `clue.reveal`

- **Статус:** предложено (план этапа 3a, утверждён владельцем)
- **Дата:** 2026-10-16

## Контекст
В `audio_blackout` игрок слышит звук фильма; на ревиле логично показать кадр. Набор
ассетов привязан к одному исходнику и виду, смешивать звук и кадр в одном наборе —
ломать модель `AssetSet`.

## Решение
- Необязательное `clue.reveal {type, params}` в конфиге: ревил подаётся загадкой
  другого типа того же домена (последний уровень).
- game ищет второй набор по `params_hash(clue.reveal.params)`; единица играбельна, только
  если готовы оба набора.

## Последствия
- Ревил любого режима настраивается конфигом. Без `clue.reveal` поведение этапа 2.
