# 0067. Теги сборника в событиях и фильтр находки `collection_tags`

- **Статус:** черновик
- **Дата:** 2026-10-25
- **Уточняет:** [0055](0055-event-find-triggers.md) (триггеры находок), [0028](0028-collections-versions-draft-projection.md) (проекция сборников в game)
- **Решение владельца:** 2026-10-25

## Контекст
Триггер `collection_played` фильтровался только списком `collection_keys` (id сборников). Для сезонных событий нужен фильтр по смыслу («новогодний сборник»), а не по id. Теги сборника жили только в collections, а `game.GameFinished` их не нёс. Отдельно: `CollectionPublished/Updated` не несли названия, поэтому `CommentPosted.collection_title` в social оставался пустым.

## Решение
1. **События collections.** В `CollectionPublished/Updated` добавлены необязательные поля `tags` (ключи тегов, ≤ 20 по ≤ 32 символа, `^[a-z][a-z0-9_]{0,31}$`) и `title` (нормализованное название, ≤ 120). Обратно совместимо: потребители без поля работают как раньше. Описание по-прежнему в события не попадает.
2. **game.** Проекция `collection_proj.tags` (JSONB, миграция `0008`, expand). Сессия по сборнику фиксирует теги на старте (в `game_sessions.state.collection.tags`, без миграции таблицы сессий), как `collection_version`; правка тегов сборника на идущую сессию не влияет. `GameFinished.collection_tags` — необязательный массив, пусто — не сборник, у сборника нет тегов или проекция получена из события старого формата.
3. **progression.** Необязательный `params.collection_tags` у серверного триггера `collection_played` (до 20 тегов, без повторов, ключи как в collections; у других метрик — 422). Находка засчитывается, если у сыгранного сборника есть хотя бы один из тегов; пусто или нет — без фильтра. Событие без `collection_tags` не проходит фильтр по тегу. **С `collection_keys` — «и»:** если заданы оба фильтра, должны пройти оба.
4. **social.** Проекция сборника берёт `title` из события (≤ 120); событие без `title` не затирает известное название. Уведомление `comment_posted` получает название вместо пустой строки.
5. **Сид.** Тег `new_year` добавлен в словарь `meta.yaml` collections (и перевод `collections.tags.new_year`), в сидовый `film-frames`; находка «Подарок из сборника» события «Новый год» использует `collection_tags: [new_year]`.

## Последствия
- Название сборника (UGC) теперь попадает в топик `collections.collection.v1`. Оно уже нормализовано `gv_text.ugc` при публикации; потребители, кроме social, его не хранят (game по-прежнему игнорирует).
- Сборники, опубликованные до выката, не имеют тегов в проекции game, пока collections не пришлёт новое событие по сборнику; сезонные находки по тегам до этого их не засчитывают.
- Откат миграции game `0008` удаляет только колонку (проекция пересобирается из событий).
