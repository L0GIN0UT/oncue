# Документация

- Один факт — в одном месте, в остальных — ссылка. Карта — `docs/README.md`, сайт — `mkdocs.yml` (`nav`).
- Принятый ADR не редактируется: новое решение = новый ADR («заменяет/уточняет NNNN»).
- `CLAUDE.md` сервиса — 10–15 строк «Особенностей»; корневой `CLAUDE.md` — только нерушимые правила и команды.
- Проверка: `uv run mkdocs build --strict`.
