# Python в Guessverse

- Слои: `domain` — чистый Python без FastAPI/SQLAlchemy/Redis; `application` зависит только от портов; инфраструктура и API — снаружи. Межсервисные импорты запрещены (import-linter).
- Время и случайность — через порты `Clock`/`Random`, не `datetime.now()`/`random` в домене.
- Ошибки — исключения из `gv_core.errors` с машинным `code`; на HTTP их мапит `libs/service`. Без голого `except`, без проглатывания.
- Логи — `structlog.get_logger(__name__)`, событие как ключ (`log.info("game.started", ...)`), без `print`; секреты и PII не логировать, не форматировать в строку события.
- Типизация `mypy --strict`; `Any` и `type: ignore[код]` — только с комментарием-причиной.
- Докстринги Google style на русском для публичных классов domain/application, портов, плагинов, libs. Комментарии — «почему», со ссылкой на ADR при необходимости.
- Конфиги — `pydantic-settings` через env (`GV_*`). Никаких хардкод-значений режимов, лимитов, цен.
- Форматирование и автоисправления ruff запускаются хуком после каждой правки; оставшиеся замечания исправь.
