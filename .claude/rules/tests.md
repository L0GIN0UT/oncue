# Тесты

- Уровни и маркеры: `unit` (без IO), `integration` (реальная инфраструктура через фикстуру `infra`), `component` (сервис + заглушки), `contract`. Маркер уровня обязателен (`pytestmark`).
- Инфраструктура тестов — только из `gv_testkit`. Нужного нет — добавь в testkit с тестом.
- Не мокай тестируемый код; проверяй поведение, а не реализацию. Баг-фикс — с тестом, который падал до исправления.
- Детерминизм: `FakeClock`, seed для случайности; уникальные имена ресурсов в брокерах (хвост `uuid7().hex`, а не начало — оно зависит от времени).
- Ожидание асинхронного результата — опросом с таймаутом (`asyncio.timeout`), не фиксированным `sleep`.
- Запуск: `uv run gv test <модуль> [--level L]`.
