# Схема БД и миграции

- Только обратно совместимые изменения: expand → migrate → contract (сначала добавить, потом перенести данные, удалить — отдельным релизом).
- Применённые миграции не редактируются — только новые. Перед коммитом: `backend-design:review-migration`.
- Инварианты — в схеме (NOT NULL, CHECK, UNIQUE, FK внутри сервиса), а не только в коде.
- Ключи — UUID v7; время — `timestamptz` UTC; деньги — `bigint` копеек; расширяемые перечисления — строками, не Postgres ENUM.
- Большие таблицы (результаты игр, ledger, история) — партиционирование по времени (`docs/architecture/data.md` §4).
