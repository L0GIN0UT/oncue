---
description: "Починить красные проверки (lint, типы, контракты, тесты) минимальными правками."
---

Используй агента **build-error-resolver**.

Текущие ошибки:
!`uv run gv lint 2>&1 | tail -60`

Чини группами от корневой причины, после каждой группы перезапускай проверку. Проверки не отключать, тесты не удалять. В конце — отчёт: причина → исправление → результат.
