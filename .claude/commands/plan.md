Задача: $ARGUMENTS

Если задача в одном сервисе и без новых контрактов — составь план сам, в основной сессии (поиск — агентом `explorer`). Агент **planner** (opus) — только для задач на несколько сервисов, с контрактами или ADR.

1. Передай агенту задачу и текущий этап из `docs/09-roadmap.md`.
2. Покажи пользователю план целиком.
3. **Остановись и дождись явного подтверждения.** Без «да» код не пишется.
4. Если план требует архитектурного решения — предложи сначала `/orchestrate architecture`.
