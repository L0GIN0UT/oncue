Используй агента **tdd-guide** для: $ARGUMENTS

Порядок обязателен:
1. Тест, описывающий поведение → запуск → он **падает** по правильной причине (покажи вывод).
2. Минимальная реализация → тест зелёный.
3. Рефакторинг при зелёных тестах.
4. Финал: `uv run gv test <модуль>` и `uv run gv lint` зелёные.

Если реализуется по утверждённому плану — иди по его шагам и отмечай выполненные.
