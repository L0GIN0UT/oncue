Используй агента **doc-updater**.

Изменения с последнего коммита:
!`git diff --stat HEAD`

Контекст от пользователя: $ARGUMENTS

Обнови только затронутые документы по таблице из описания агента, затем `uv run mkdocs build --strict`. Отчёт — список документов и что изменилось.
