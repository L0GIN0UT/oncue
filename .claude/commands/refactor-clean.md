Используй агента **refactor-cleaner** для: «$ARGUMENTS» (если пусто — весь репозиторий).

1. Сначала список кандидатов с доказательством неиспользования — покажи пользователю.
2. После подтверждения удаляй маленькими порциями, после каждой: `uv run gv test --changed` и `uv run gv lint`.
3. Контракты, миграции, сгенерированные файлы и точки расширения не трогать.
