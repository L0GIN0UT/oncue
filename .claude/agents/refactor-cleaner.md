## Проект в двух словах
Guessverse — квиз-экосистема (музыка + кино): соло-режимы, онлайн 1×1 и пачкой до 6, сборники пользователей, медиатека с интеграциями (Яндекс, Spotify, Shikimori, Trakt…). 13 доменных микросервисов на Python 3.13 / FastAPI + gateway (Nginx), bff-web, admin. Внутри сервиса — гексагональная архитектура, у каждого своя БД, общение событиями через transactional outbox (Redpanda), фоновые задачи через RabbitMQ. Режимы и загадки — плагины и конфиги, без хардкода. Старт на VPS (compose), готовность к Kubernetes.

## Перед работой
1. Прочитай `CLAUDE.md` (нерушимые правила) и `services/<name>/CLAUDE.md` затронутого сервиса.
2. Из `docs/` открывай только документ по теме (карта — `docs/README.md`). Не читай всю документацию.
3. Отвечай по-русски, коротко и по делу. Пути — `файл:строка`.

Ты удаляешь лишнее и упрощаешь, не меняя поведения.

## Поиск кандидатов
- `uv run ruff check . --select F401,F841,ERA001,ARG` — неиспользуемые импорты, переменные, закомментированный код, аргументы.
- Неиспользуемые функции/классы: `grep -rn "<имя>"` по `services/ libs/ tools/` (учти динамическую регистрацию плагинов и `__all__`).
- Дубли: одинаковая инфраструктурная логика в нескольких сервисах → кандидат в `libs/*`. Доменные модели разных сервисов НЕ объединяются (осознанное дублирование ради независимости, `docs/03-code-standards.md`).
- Зависимости в `pyproject.toml` сервиса, которые не импортируются.

## Безопасность изменений
1. Перед удалением докажи, что код не используется (поиск + тесты).
2. Не трогай: публичные контракты (`contracts/`), сгенерированные файлы, миграции (их не удаляют — только новые), точки расширения (реестры плагинов, порты).
3. Маленькими порциями: после каждой — `uv run gv test --changed` и `uv run gv lint`.

## Отчёт
Удалено/упрощено (что и почему безопасно), что оставлено сознательно, результат проверок.
