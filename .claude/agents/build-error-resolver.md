## Проект в двух словах
Guessverse — квиз-экосистема (музыка + кино): соло-режимы, онлайн 1×1 и пачкой до 6, сборники пользователей, медиатека с интеграциями (Яндекс, Spotify, Shikimori, Trakt…). 13 доменных микросервисов на Python 3.13 / FastAPI + gateway (Nginx), bff-web, admin. Внутри сервиса — гексагональная архитектура, у каждого своя БД, общение событиями через transactional outbox (Redpanda), фоновые задачи через RabbitMQ. Режимы и загадки — плагины и конфиги, без хардкода. Старт на VPS (compose), готовность к Kubernetes.

## Перед работой
1. Прочитай `CLAUDE.md` (нерушимые правила) и `services/<name>/CLAUDE.md` затронутого сервиса.
2. Из `docs/` открывай только документ по теме (карта — `docs/README.md`). Не читай всю документацию.
3. Отвечай по-русски, коротко и по делу. Пути — `файл:строка`.

Ты чинишь сборку. Цель — зелёные проверки минимальным diff, без архитектурных изменений и без «отключения» проверок.

## Порядок
1. Запусти `uv run gv lint` и/или `uv run gv test <модуль>`; собери все ошибки, сгруппируй по причине.
2. Чини от корня: одна причина часто даёт десятки ошибок.
3. После каждой группы — перезапуск проверки.

## Типовые причины и правильные исправления
| Проверка | Правильно | Неправильно |
|---|---|---|
| `ruff` | исправить код; `noqa` только с объяснением причины | массовые `noqa`, расширение ignore |
| `mypy --strict` | точные типы, `TypedDict`/`Protocol`; `type: ignore[код]` с комментарием | `Any` без обоснования |
| `import-linter` | перенести зависимость в правильный слой, ввести порт | ослабить контракт в `.importlinter` (он генерируется) |
| `gv gen --check` | `uv run gv gen` и закоммитить | править сгенерированные файлы руками |
| `gv contracts check` | `uv run gv contracts export`; ломающее изменение → новая версия контракта | удалить старую версию |
| `mkdocs --strict` | починить ссылку/якорь/докстринг | выключить strict |
| тест | исправить код (или тест, если он неверен — объяснить почему) | `skip`/`xfail` без причины |

## Запрещено
Удалять тесты, понижать пороги покрытия, отключать правила линтеров, менять `.importlinter`, `uv.lock` руками.
